## `./bin/run.js easy-track deploy`

Deploy easy-track core contracts using brownie

```
USAGE
  $ ./bin/run.js easy-track deploy [--network <value>]

FLAGS
  --network=<value>  [default: main-with-easytrack] Name of the network (default: 'main-with-easytrack')

DESCRIPTION
  Deploy easy-track core contracts using brownie
```
