## `./bin/run.js down-offchain`

Stop offchain apps in DevNet

```
USAGE
  $ ./bin/run.js down-offchain [--network <value>] [--force] [--silent]

FLAGS
  --force            Do not check that services were already stopped
  --network=<value>  [default: main-with-easytrack] Name of the network (default: 'main-with-easytrack')
  --silent           Do not stop on errors

DESCRIPTION
  Stop offchain apps in DevNet
```
