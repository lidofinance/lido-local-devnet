`./bin/run.js stand`
====================

* [`./bin/run.js stand run`](#binrunjs-stand-run)

## `./bin/run.js stand run`

Execute a stand from a YAML configuration file

```
USAGE
  $ ./bin/run.js stand run --file <value> [--network <value>]

FLAGS
  --file=<value>     (required) Path to stand YAML file
  --network=<value>  [default: main-with-easytrack] Name of the network (default: 'main-with-easytrack')

DESCRIPTION
  Execute a stand from a YAML configuration file
```
